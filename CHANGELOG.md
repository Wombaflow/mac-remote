# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-09

### Added
- iPhone-as-trackpad web UI: move, tap, double tap, hold-to-drag, two-finger scroll and right click.
- Edge scrolling with one finger along either screen edge.
- Optional gyro mode driven by device tilt, with speed and axis-inversion controls.
- On-screen text input that types into the focused Mac app.
- Visual feedback: glow, motion trail, click ripples and scroll ticks.
- PIN protection with persistent PIN and rate limiting.
- HTTP and self-signed HTTPS endpoints (HTTPS is required by iOS for motion sensors).
- English and Ukrainian UI; `--version` flag.
